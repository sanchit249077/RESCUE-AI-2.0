# Candidate authoritative / public data sources

- Geological Survey of India (Bhusanket): https://bhusanket.gsi.gov.in/
  - Current portal exposes a field-validated landslide inventory and state susceptibility resources.
- ISRO Bhuvan 2D: https://bhuvan-app1.nrsc.gov.in/bhuvan2d/bhuvan/bhuvan2d.php
  - Current portal exposes landslide and land-cover/geospatial layers.
- ISRO Bhuvan IMD products: https://bhuvan-app1.nrsc.gov.in/imd/
  - Current portal exposes spatial weather products and soil-moisture products.
- OpenStreetMap: https://www.openstreetmap.org/
  - Road/settlement base layers.

Before deployment, confirm access terms, update frequency, licensing and API/service availability.

## Verified live source observations (checked 2026-09-04)
- GSI Bhusanket currently lists a field-validated landslide inventory and state susceptibility resources, including Arunachal Pradesh, Manipur, Meghalaya, Mizoram, Nagaland and Sikkim.
- ISRO Bhuvan currently exposes Landslides, Land Cover and Natural Resources, Infrastructure (Road & Rail), Settlement Locations and other layers.
- Bhuvan IMD currently exposes spatial weather parameters and soil-moisture products.
- IMD current rainfall information page exposes district/state rainfall views and forecast products.

These observations are web-verified and should be rechecked before production integration.
